## Описание

Многостраничный сайт фотостудии, разработанный с использованием фреймворка Bootstrap 5.
Проект включает 5 страниц с адаптивной вёрсткой, готовыми компонентами и интерактивными элементами.

## Практическая работа 9

- Создан проект `kr2-bootstrap-shop`.
- Подключён Bootstrap локально через папку `vendor/bootstrap/`.
- Создана главная страница на Bootstrap-сетке.
- Реализованы hero-блок, преимущества и карточки.

## Практическая работа 10

- Созданы страницы `catalog.html`, `product.html`, `order.html`, `contacts.html`.
- Добавлена единая Bootstrap-навигация (`navbar`).
- Использованы компоненты: `card`, `btn`, `badge`, `alert`, `modal`, `accordion`.
- Добавлена форма записи с `form-control`, `form-select`, `input-group`, `form-check`.
- Обновлён `css/custom.css` (тёплая палитра студии).
- Добавлена кнопка «Наверх».

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — залы и форматы;
- `product.html` — карточка зала;
- `order.html` — форма записи;
- `contacts.html` — контакты и отзывы;
- `css/custom.css` — дополнительные стили;
- `vendor/bootstrap/` — файлы Bootstrap;
- `images/` — изображения проекта;
- `README.md` — описание проекта.

## Способ подключения Bootstrap

Bootstrap подключён локально из папки `vendor/bootstrap/`.
Используются файлы `bootstrap.min.css` и `bootstrap.bundle.min.js`.

## Реализованные компоненты

- `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `accordion`, `form-control`, `form-select`, `input-group`, `form-check`.

## Как проверить

1. Открыть `index.html` в браузере.
2. Проверить навигацию, карточки, модальное окно и адаптивность.
3. Открыть `catalog.html` — проверить фильтры и карточки.
4. Открыть `product.html` — проверить карточку зала, аккордеон и таблицу.
5. Открыть `order.html` — проверить форму записи.
6. Открыть `contacts.html` — проверить контакты и отзывы.
7. Проверить адаптивность через DevTools (375px, 768px, 1024px, 1440px).
